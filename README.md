# emredagci/tap

Homebrew formulae for [sbrain](https://github.com/emredagci/sbrain).

```bash
brew install emredagci/tap/sbrain
```

`Formula/sbrain.rb` is written by sbrain's release workflow; change
[the template](https://github.com/emredagci/sbrain/blob/main/packaging/homebrew/sbrain.rb.in) instead.
